# 污斑兔的书籍作品

Wubuntu(污斑兔) 的 AI 技术书籍作品集。

## 书籍

- [AI 使用能力八级](https://books.wubuntu.cn/ai-8-level/) — 从认识到精通，八级递进的能力链条
- [AI Context Workspace](https://books.wubuntu.cn/acw/) — 你值得拥有的长期上下文管理方案

## 技术栈

- [VitePress](https://vitepress.dev/) — 静态站点生成
- [Cloudflare Pages](https://pages.cloudflare.com/) — 托管与部署
- 自定义域名：`books.wubuntu.cn`

## 本地开发

```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # 构建到 docs/.vitepress/dist
```
